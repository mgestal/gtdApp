Kanban

Organiza visualmente las tareas activas mediante expresiones de etiquetas o prioridades.

Cómo funciona el tablero
Cada card, excepto Inbox, usa una expresión de etiquetas o una prioridad.
Inbox
Muestra las tareas activas que no pertenecen a ningún proyecto ni carpeta. Es una card fija: no se puede editar ni eliminar.
Cards de reglas
Una tarea aparece en la primera card cuya expresión de etiquetas o prioridad coincida. El orden de las cards define la prioridad cuando una tarea coincide con más de una regla.
Las tareas de las carpetas EnEspera, Seguimiento y Sometime se agrupan dentro de su card de estado para mantener el tablero ordenado.
Información de cada tarea
Las tarjetas muestran prioridad, proyecto, carpeta y fecha cuando están definidos. Los enlaces de proyecto y carpeta abren su detalle.
Expresiones de etiquetas
Combina etiquetas para definir con precisión qué tareas muestra una card.
Operador Significado Ejemplo
^ AND: la tarea debe tener ambas etiquetas. @pocotiempo ^ @pocaenergia
| OR: la tarea debe tener al menos una de las etiquetas. @casa | @oficina
! NOT: la tarea no debe tener la etiqueta indicada. @llamadas ^ !@delegada
Las etiquetas deben empezar por @. No se admiten paréntesis. La precedencia es !, después ^ y finalmente |; por ejemplo, @casa | @oficina ^ !@delegada equivale a @casa | (@oficina ^ !@delegada).
Mover y completar tareas
Actualiza el estado sin salir del tablero.
Arrastra una tarea a una card con una única etiqueta para asignársela, o a una card de prioridad para actualizarla. Las cards con expresiones compuestas solo se usan para mostrar tareas, porque no hay una modificación única que pueda deducirse de una expresión. Al moverla a Inbox, se elimina la etiqueta de estado Kanban de una card de etiqueta simple.
Usa el círculo situado junto al título de la tarea para marcarla como realizada o desmarcarla. Las tareas completadas dejan de mostrarse en el tablero.
Para crear una tarea directamente en Inbox, pulsa + Nueva tarea en el encabezado de esa card.
Crear y configurar cards
Adapta los estados a tu flujo de trabajo.
Pulsa + Añadir card, en la barra superior o al final del tablero, indica un nombre y selecciona el criterio. Para una expresión de etiquetas, escribe una o varias etiquetas con los operadores disponibles. Para prioridad, selecciona Alta, Media o Baja. La nueva card se añade al final.
El icono de configuración de una card permite cambiar su nombre y su regla, y eliminarla.
Al eliminar una card no se eliminan sus tareas, sus etiquetas ni sus prioridades; simplemente dejan de aparecer en ese tablero hasta que coincidan con otra card.
Paneles y filtros
Guarda distintas vistas para cada contexto de trabajo.
Selecciona un panel en el desplegable. Desde el icono de configuración puedes crear un panel vacío, guardar una copia del actual, renombrarlo o eliminarlo. Debe permanecer al menos un panel.
Usa los filtros de texto, card, proyecto y carpeta para centrarte en las tareas relevantes. Al filtrar por carpeta puedes incluir también sus subcarpetas.
Ejemplo: crea un panel “Trabajo” con las cards @Pendiente, @EnCurso, @EnEspera y una card de prioridad Alta; después filtra por el proyecto de una entrega para revisar su avance.
