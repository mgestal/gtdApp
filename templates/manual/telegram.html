❓Manual: Integración con Telegram

Configuración del bot, permisos y envío de resumen diario.

Ficheros necesarios
.token-gtdapp: token del bot creado en BotFather.
instance/telegram_chat.json: chat registrado para envíos automáticos.
Flujo de configuración
1. Crear bot en BotFather y copiar token.
2. Guardar token en .token-gtdapp.
3. Configurar usuarios/grupos autorizados en instance/config.json (bloque security).
4. Iniciar conversación con el bot para registrar el chat.
Uso
El bot puede guardar el chat activo y enviar recordatorios/resúmenes.
El script send_today.py envía el resumen de tareas del día al chat configurado.
Los recordatorios se crean en cada tarea y requieren el proceso periódico de envío. Consulta la guía de recordatorios y notificaciones para configurar los canales, el horario y las pruebas.
