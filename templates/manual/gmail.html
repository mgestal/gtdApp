❓ Manual: Integración con Gmail

Cómo preparar OAuth y usar la importación de correos a Inbox.

Ficheros necesarios
instance/gmail_credentials.json: credenciales OAuth descargadas de Google Cloud.
instance/gmail_token.json: token generado tras autorizar la cuenta.
Flujo de configuración
1. Crear OAuth Client ID en Google Cloud.
2. Descargar el JSON y guardarlo como instance/gmail_credentials.json.
3. Ejecutar el flujo de autorización manual para generar instance/gmail_token.json.
4. Verificar permisos de lectura para el usuario que ejecuta la app (por ejemplo, www-data en Apache).
Uso en la aplicación
Desde la pantalla principal puedes importar correos y convertirlos en tareas de Inbox.
La app evita importar dos veces el mismo mensaje.
Si cambias credenciales o permisos OAuth, normalmente hay que regenerar el token.
