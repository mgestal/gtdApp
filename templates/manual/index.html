❓ Manual de usuario

Guía práctica de GTD App: qué hace cada sección, cómo usarla y ejemplos habituales.

Visión general
La app está organizada para capturar, aclarar, organizar y revisar tareas con un flujo GTD.
Objetivo principal
Gestionar tareas, proyectos, etiquetas, carpetas, revisiones y sincronización con Google Calendar desde una única interfaz.
Flujo recomendado
1. Captura en Inbox. 2. Aclara y clasifica. 3. Ejecuta desde Hoy, NextActions o Próximo. 4. Revisa con Review y Dashboard.
Añadir tareas
Puedes crear tareas desde el botón + Añadir tarea o desde formularios rápidos en varias vistas.
Sintaxis rápida: nombre + [@etiquetas] + [*fecha] + [h:HH:MM] + [#proyecto | #"proyecto con espacios"] + [f:carpeta | f:"carpeta con espacios"] + [cada {día|semana|mes|año}]
Ejemplo Qué hace
Llamar a Juan @NextAction *mañana Crea una tarea para mañana con la etiqueta NextAction.
Podar árboles #Jardin Crea una tarea asociada al proyecto Jardin.
Revisar plan #"Area Personal" Asocia la tarea al proyecto "Area Personal" (nombre con espacios, entre comillas).
Tarea de rutina f:Rutinas Asigna la tarea directamente a la carpeta Rutinas.
Revisar agenda f:"GTD Folders" Asigna la tarea a la carpeta "GTD Folders" (nombre con espacios, entre comillas).
Act. cuentas @Finanzas *+3 h:09:00 cada mes Crea una tarea con fecha dentro de 3 días, hora 09:00 y recurrencia mensual.
Llamar proveedor ^alta @NextAction *hoy Asigna prioridad Alta al crear la tarea (también existe ^media y ^baja).
Si no indicas prioridad, la tarea queda sin prioridad (valor nulo).
Autocompletado en el campo de texto: al escribir @ se sugieren etiquetas, al escribir # se sugieren proyectos y al escribir f: se sugieren carpetas. Usa las teclas ↑↓ para navegar y Enter o clic para insertar. Los nombres con espacios se insertan automáticamente entrecomillados.
Prioridades y barra de color
Cómo funcionan las prioridades en las listas de tareas.
Alta = barra roja, Media = barra ámbar, Baja = barra verde.
La barra aparece a la izquierda del checkbox en las vistas de ejecución (por ejemplo: Today, Week, NextActions, Próximo, filtros y detalles).
Si una tarea no tiene prioridad, no se muestra barra.
Secciones principales
Accesos más usados del menú lateral y barra superior.
Inbox
Bandeja de entrada para capturar tareas sin proyecto ni carpeta.
Ejemplo: anotar “Renovar seguro del coche” y clasificarla después.
El botón 🗄 Archivar realizadas envía al archivo todas las tareas completadas del Inbox de una vez.
Hoy
Tareas relevantes para hoy. Útil para enfoque diario.
Ejemplo: revisar llamadas pendientes, pagos y recados del día.
Esta semana
Vista de tareas que debes atender en el corto plazo semanal.
Ejemplo: preparar reunión, entregar documentación o compras semanales.
NextActions
Lista de próximas acciones ejecutables. Muy útil para trabajar por contexto o disponibilidad.
Ejemplo: “Enviar mail al proveedor”, “Pedir cita médica”, “Comprar bombillas”.
⟲ Tareas periódicas
Las tareas con recurrencia muestran el chip ⟲ periódica en rojo. Al hacer clic se abre el histórico de ejecuciones: fecha y hora de cada vez que se completó, vencimiento anterior y siguiente previsto.
Ejemplo: comprobar las veces que se ha realizado una revisión mensual o verificar que una rutina semanal se ejecutó correctamente.
Próximo
Agenda de próximos compromisos y tareas con fecha.
Ejemplo: una cita médica a las 10:00 o una entrega el viernes.
Calendario
Vista calendario interna para revisar tareas fechadas y su distribución temporal.
Ejemplo: ver de un vistazo la carga de eventos de la semana.
Etiquetas
Permiten clasificar tareas por contexto, estado o temática.
Ejemplo: @NextAction, @agenda, @EnEspera, @Finanzas.
Filtros
Consultas guardadas para localizar subconjuntos de tareas según reglas.
Ejemplo: tareas con etiqueta @Finanzas y vencimiento esta semana.
También puedes filtrar por prioridad (ejemplo: prioridad:alta).
Ver sintaxis completa de expresiones de filtros
Proyectos
Agrupan tareas relacionadas con un resultado concreto.
Ejemplo: “Mudanza”, “Artículo revista”, “Reforma del despacho”.
Carpetas
Agrupan proyectos y tareas por áreas, horizontes o contenedores organizativos.
Ejemplo: Trabajo, Casa, Algún día, Checklists, Rutinas.
Búsqueda
Permite encontrar tareas, proyectos u otros elementos por texto.
Ejemplo: buscar “factura”, “Amazon” o “sexenio”.
Revisión y control
Herramientas para mantener el sistema limpio y fiable.
Review
Guía de revisión semanal con bloques de trabajo: Inbox, NextActions, agenda, EnEspera (tareas y proyectos en carpeta EnEspera), proyectos, checklists, etc.
Ejemplo: usarla los viernes para vaciar inbox, revisar en espera y detectar proyectos sin acciones.
Ver plantilla de review con filtros recomendados
Dashboard
Resumen ejecutivo de tareas abiertas, completadas y próximos vencimientos.
Ejemplo: comprobar cuántas tareas completaste esta semana y qué vence en 7 días.
Archivo
Contiene tareas y proyectos archivados para consulta o recuperación posterior.
Ejemplo: revisar una tarea que fue archivada al borrar un evento en Google Calendar.
Filtros
Puedes crear filtros avanzados combinando etiquetas, proyectos, carpetas, fechas y operadores lógicos.
Guía ampliada
La documentación completa incluye prefijos como f:, p:, fa:, pf:, operadores lógicos y palabras clave.
Abrir explicación completa de expresiones de filtros

Resumen de integraciones disponibles y acceso a su documentación completa.

Configuración
La configuración principal se guarda en instance/config.json.
Bloque db
Define la conexión con MariaDB: host, puerto, usuario, contraseña, base de datos y juego de caracteres.
Ejemplo habitual: usar 127.0.0.1, puerto 3306 y la base gtd.
Bloque app
Incluye opciones generales como la zona horaria, el título mostrado en la interfaz y parámetros de paginación.
En esta instalación se usa la zona Europe/Madrid y el título GTD App.
calendar_sync.calendar_id
Indica el calendario de Google que se usa para sincronizar tareas y para importar eventos a Inbox.
Ejemplo: mgestal@gmail.com para trabajar con un calendario compartido en lugar de primary.
Paginación
Los campos agenda_per_page, search_per_page, tags_per_page, folders_per_page, filters_per_page, projects_per_page, nextactions_per_page, archive_tasks_per_page, archive_projects_per_page y periodic_history_per_page limitan cuántos elementos se ven por página.
Todos estos valores también son editables directamente desde el panel Admin → Paginación sin necesidad de editar el fichero de configuración.
Bloque security
Se usa sobre todo para Telegram. Permite definir qué usuarios o grupos están autorizados con allowed_user_ids y allowed_group_ids.
La opción reply_on_unauthorized controla si el bot responde cuando alguien no autorizado intenta usarlo.
Recomendación práctica
Haz copia de seguridad de instance/config.json antes de cambiarlo y reinicia la aplicación web o el proceso correspondiente para aplicar los cambios.
🚀 Instalación y despliegue
Cómo instalar GTD App en otro equipo: Docker, instalación manual o producción en servidor.
Docker (Recomendado)
Opción más sencilla: instala la base de datos, dependencias y la app automáticamente en cualquier máquina.
Instalación manual
Para usuarios avanzados: control total sobre Python, MySQL y configuración.
Producción en servidor
Guía para ejecutar en VPS, Raspberry Pi, NAS o servidor propio con opciones de acceso remoto seguro.
Ver guía completa de instalación y despliegue
Admin
Panel para mantenimiento, sincronización y configuración avanzada.
Sincronizar ahora
Lanza la sincronización manual con Google Calendar y muestra el resultado dentro de la propia card.
Resolución de conflictos
Permite elegir “Usar Google” o “Usar GTD” si hubo cambios concurrentes.
Mantenimiento
Incluye tareas como limpiar etiquetas no usadas, borrar proyectos vacíos o archivar tareas antiguas.
Consejos de uso
  • Captura rápido en Inbox y clasifica después; evita perder ideas por querer organizarlas en el momento.
  • Usa etiquetas para contexto y carpetas/proyectos para estructura.
  • Reserva una revisión semanal con la vista Review para mantener el sistema fiable.
  • Usa Admin para lanzar sincronización manual cuando hayas tocado tareas o eventos importantes.
  • Si una tarea desaparece de las listas activas, revisa Archivo antes de asumir que se borró definitivamente.
